## Conventions & ambiguities
- **Lesson data**: taxi12 is read like truth m3.taxi12.read (`header=True, inferSchema=True`) from `BASE/lessons/taxi12.csv`; gh8 with `spark.read.json(BASE/lessons/gh8.jsonl)`. The `lessons/` folder exists only in the harness mirror (the setup notebook does not create it). Learner-facing text calls them "the 12 lesson trips" / "the 8 lesson events" and never asks learners to read that path; code they are asked to run uses the full data paths. File paths shown for gh8 (`…/lessons/gh8.jsonl`) are real harness outputs.
- **ANSI mode on, case-insensitive names** (blueprint §8.1–8.2): `Actor.Login` resolves (m3x.gh8.case_insensitive); typos in this module are real misspellings (`login` without `actor.`, `actor.logn`, the capstone's `tip_amont`).
- **Lazy vs eager** (§8.5): `select("typo")`, `filter`, `orderBy`, `agg(F.mean("typo"))` raise only at an action; `groupBy("typo")`, `df["typo"]`, `df.typo` raise on their own line. The capstone typo sits in `agg(F.mean("tip_amont"))` (Cell 7) and raises at `show()` (Cell 9). Teach as "Spark checks most names only when an action runs; a few commands look at the column list straight away".
- **Spark 4 prints NULL** in `show()`; Python reprs print `None`; pandas `NaN`.
- **BASE path** = `/Volumes/workspace/default/bdcc`; Databricks shows volume files as `dbfs:/Volumes/...` in `_metadata.file_path`, `dbutils.fs.ls` paths and error messages. This `dbfs:` prefix is an assumption carried over from the harness mapping (blueprint §8.12), not verified on Databricks; say it only in the facilitator guide.
- **Listing order**: `dbutils.fs.ls` names are shown sorted by code point (harness stub; `_SUCCESS` sorts after uppercase and before lowercase names). File times, part-file names and their number differ on Databricks: show only stable names (`VendorID=1/`, `_SUCCESS`, CSV names and sizes).
- **Group order without `orderBy`** is not guaranteed (hash order); every taught chain sorts, with a tie-break where ties exist. The engine reproduces the real unsorted orders, but lessons never rely on them.
- **Tracebacks** are trimmed per blueprint §4 (your cell frame, `  ...`, the final message, up to 4 plan lines). Databricks shows `File <command-…>` and `AnalysisException:` without the module path (said once in Session 4, M2).
- **Problem 1 timings** come from problems.json P1 (CSV = the inferSchema read used in Sessions 2–3, so inference is not timed) and are labelled "local laptop, Spark 4.0.1, median of 3". truth p1.timing is a second real run on the plain (string) CSV read (ratios 1.3–7.0); either set supports the same conclusion. Never present times as Databricks numbers.
- **Values read** (Session 5 analogy) is an idealized count of cell values (row layout n × c, column layout n × k), not a Spark output or a byte count; real Parquet also compresses and skips row groups.
- **Mean** is Spark's `avg` (`F.mean` and `F.avg` build the same `avg(col)`); sums/means are exact on taxi12 (doubles). The capstone's FLOAT schema prints float artifacts (`14.574999809265137`), real output.
- **Ties**: Spark sorts strings by code point (uppercase before lowercase): `MostafaGazar` < `Netflix` < `STRML` < `inf0rmer`.
- **Explode** drops rows whose array is NULL or empty (not `explode_outer`).
- **Grading quirks** used by quiz.yaml: code-fill strips whitespace, maps `"` to `'`, is case-sensitive.
